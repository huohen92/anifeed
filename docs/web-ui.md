# Web UI 使用文档

AniFeed 的 Web UI 与 CLI 共用同一套配置和数据库。启动：

```bash
./anifeed server
# 或
./anifeed web
```

默认监听 `0.0.0.0:8115`，浏览器打开 `http://<服务器IP>:8115`。也可以使用 `--host 127.0.0.1` 只允许本机访问。

## 页面功能

### 概览

- 115 登录状态：显示昵称、UID、VIP 标识，或提示登录失效 / 未配置。
- 统计卡片：订阅数、今日提交、云端任务数、任务完成率。
- 最近任务与最近日志；未登录 115 时回退显示本地最近提交。
- 「运行全部订阅」一键执行所有 RSS。
- 显示自动运行状态（未开启 / 每 N 分钟）。
- 未创建 `config.toml` 或检测到旧版配置时，会显示迁移提示。

### 订阅管理

![订阅管理](./screenshots/feeds.png)

每个卡片对应 `config.toml` 中的一条 `[[rss]]`：

| 字段 | 说明 |
| --- | --- |
| 订阅名称 | 必填，用于历史记录和界面展示 |
| 来源 | Mikan / AniBT / AnimeGarden / 其他，写入 `source` |
| 站点 | 保存时自动从 RSS 地址的域名补全 |
| RSS 地址 | 必填，支持 http/https |
| 启用 | 是否参与自动运行 / 全部运行，对应 `enabled` |
| cid | 115 目录 ID，留空使用设置中的默认目录 |
| savepath | 离线保存路径，留空使用设置中的默认路径模板 |
| filter | 白名单：标题包含该文字才离线；`/正则/` 写法使用正则 |
| exclude | 黑名单：标题包含该文字则跳过；同样支持 `/正则/` |
| 缓存过期 | 可选，写入 `expiration` 字段 |

操作：

- **立即运行**：抓取 RSS，按全局排除、filter/exclude 过滤并把新条目提交到 115。
- **测试订阅**：只抓取并预览匹配结果，不会提交任何任务。
- **启用 / 禁用**：禁用后不会参与自动运行和「运行全部」，但仍可手动立即运行。
- **编辑 / 删除**：直接修改 `config.toml`，保存后热重载。
- 卡片右上角的复制按钮可以复制 RSS 地址。

#### 订阅来源

添加订阅时先选择来源，程序会根据 ID 自动生成 RSS 地址；也可以直接覆盖 RSS 地址输入框。

| 来源 | 需要填写的字段 | 生成的 RSS |
| --- | --- | --- |
| **Mikan** | 番剧 ID、字幕组 ID（可选） | `https://mikanani.me/RSS/Bangumi?bangumiId=...&subgroupid=...` |
| **AniBT** | Bangumi 番剧 ID、字幕组 groupSlug（可选） | `https://anibt.net/rss/anime.xml?bgmId=...&groupSlug=...` |
| **AnimeGarden** | Bangumi 番剧 ID（subject）、字幕组名称（可选） | `https://api.animes.garden/feed.xml?subject=...&fansub=...` |
| **其他** | RSS 地址 | 手动填写任意 RSS |

![添加订阅](./screenshots/feed-modal.png)

- 每个来源面板都提供「打开站点」链接，可在站点中查找番剧 ID 和字幕组。
- Mikan 的站点地址可以在设置中改成镜像站（`subscription.mikan_host`）。
- 「其他」会从条目的 enclosure、description 中提取 magnet / ed2k，也支持直接 HTTP(S) 下载链接；`.torrent` 文件地址会被忽略，避免 115 把种子文件当成普通文件下载。
- `source` 会写入配置，即使使用 Mikan 镜像域名也能正确选择解析器。

#### 站内浏览

![站内浏览](./screenshots/browse.png)

「订阅管理 → 浏览站点」以及添加订阅弹窗里的「在 X 中浏览」会打开站内浏览：

- **AniBT**：按季度、星期浏览；展开番剧可查看字幕组和最近资源，点击「添加订阅」自动填入 RSS。
- **AnimeGarden**：按星期浏览当前番剧，支持标题搜索；展开后按字幕组生成 RSS。
- **Mikan**：搜索番剧或输入 `id: 3548`，展开后按字幕组生成 RSS。
- 已订阅的番剧显示「已订阅」标记。
- 浏览只读取站点公开接口；添加前仍会打开订阅表单，可继续修改名称、filter/exclude、cid 和保存路径。

> 站点浏览需要服务器能访问对应站点。Mikan 官方域名无法访问时会自动尝试 `https://mikanime.tv` 镜像；也可以在「设置 → 自动运行 → Mikan 站点地址」手动指定。AniBT/AnimeGarden 使用公开 JSON API。

### 离线任务

- 读取 115 云端离线任务，支持全部 / 运行中 / 已完成 / 失败 / 等待中筛选。
- 展示大小、进度、任务 hash，可复制 hash。
- 「添加链接」支持批量粘贴 magnet、ed2k、http(s)、ftp 链接，可指定 cid 和保存路径。
- 「清理任务」支持清除已完成、失败、运行中、全部，以及清除并删除文件（危险操作会二次确认）。

> 清理只作用于 115 的离线任务列表；带「删除文件」的选项才会动网盘文件。

### 历史记录

- 读取本地 `db.sqlite` 的 `rss_items` 表，按订阅名称过滤。
- 显示标题、订阅、提交时间和 115 任务 hash。
- 用于排查「为什么某条没有重复提交」：默认会按 magnet 去重。

### 运行日志

- 展示服务端最近 800 行日志，3 秒自动刷新（可关闭）。
- 错误、警告、成功行会着色，便于定位抓取失败、115 拒绝任务等问题。

### 设置

![设置](./screenshots/settings-offline.png)

设置页统一使用表单编辑，不再提供「原始 TOML」页面标签。

设置包含：

- **115 登录**：Cookies 输入框、扫码登录、退出登录。
- **服务与访问**：监听地址、端口、访问令牌。
- **数据库与缓存**：数据库路径、禁用去重、分块延迟、分块大小、冷却时间。
- **网络代理**：HTTP 代理地址。
- **默认离线设置**：默认保存路径模板、默认 115 目录 ID、全局排除、跳过 x.5、失败重试、运行后自动清理。
- **自动运行**：开关、间隔、启动时立即运行、RSS 超时、Mikan 站点地址。
- **通知**：Webhook 地址、通知方式、推送内容、成功/失败开关、测试通知。
- **站点选项**：为特定域名启用代理，追加任意请求头（例如 Referer、Cookie）。

#### 默认保存路径模板

当订阅没有填写 `savepath` 时使用 `offline.default_savepath`，支持以下变量：

| 变量 | 说明 |
| --- | --- |
| `${title}` / `${name}` | 订阅名称 |
| `${site}` | RSS 域名 |
| `${year}` | 当前年份 |
| `${month}` | 当前月份（两位数） |
| `${day}` | 当前日期（两位数） |
| `${season}` | 当前季度，如 `2026秋` |

例如 `番剧/${title}` 会保存到 `番剧/药屋少女的呢喃 · 简日`。变量替换值会自动清理 `/ : * ? " < > |` 等非法字符。

订阅级 `savepath` 和 `cid` 的优先级高于默认值。

默认目录输入框旁边的「选择」按钮会打开 115 目录浏览器，支持逐级进入、面包屑返回、新建文件夹和选择当前目录。订阅编辑弹窗中的 cid 也提供同样的选择器。

![选择 115 目录](./screenshots/folder-picker.png)

#### TMDB 关联

在「设置 → TMDB」配置 `TmdbApi`、`TmdbApiKey`、`TmdbImage`。

订阅编辑里：

- **自动**：按订阅名称清洗后自动搜索，并填入最匹配的 TMDB ID
- **搜索**：手动搜索并选择
- 关联后可在重命名模板中使用 `${tmdbid}`，海报优先使用 TMDB 封面

#### 规则库 / 细分匹配

点击「添加订阅」会先弹出匹配偏好面板；编辑订阅时也可以点击表单里的「规则库 / 细分匹配」：

![匹配偏好](./screenshots/match-preferences.png)


- 「自动应用最佳规则」会基于当前 RSS 标题自动选择简体、内封/内嵌、1080p、MKV 等可用组合
- 语言、字幕类型、容器格式、分辨率选择会生成 `filter`（必须包含）和 `exclude`（排除同类其他项）
- 字幕组排除预设来自 [AB_AR_exclude_regular_expressions](https://github.com/jacksen168sub/AB_AR_exclude_regular_expressions)
- 生成结果会写回订阅的 filter/exclude 输入框，仍可手动修改
- 规则下方实时显示匹配到的 RSS 条目和「将下载 / 跳过」
- 默认显示规则匹配条目；「自动」只显示自动建议，「显示 RSS 全部内容」会包含被 filter/exclude 过滤掉的条目
- 「自动」和「显示 RSS 全部内容」都支持再次点击取消，回到默认视图
- 自动优选只在规则匹配的条目中按集数评分，规则过滤的条目不参与
- 应用后需要保存订阅

#### 逐条预览

订阅编辑里的「预览」按钮会打开类似 ani-rss 的逐条预览：

![逐条预览](./screenshots/item-preview.png)

- 是否下载：可逐条切换；全选/全不选支持再次点击切换；可批量允许/禁止
- 删除已下载：勾选条目后强制删除本地下载历史和后台处理记录
- 可勾选「同时删除云盘文件与离线记录」；删除前会二次确认，删除不可恢复
- 已下载：来自本地历史记录
- 主RSS：当前订阅
- 字幕组、标题、重命名结果
- 保存后会写入本地 SQLite，运行订阅时优先使用这些选择

#### 自动优先顺序

「设置 → 默认离线设置」可调整「自动应用最佳规则」的优先顺序：

- 语言：简体 / 繁简 / 繁体
- 字幕：内封 / 内嵌 / 外挂
- 容器：MKV / MP4
- 分辨率：1080p / 4K / 720p

用每项右侧的上下箭头调整，保存后生效。

#### 重命名与离线后转移到保存文件夹

![重命名设置](./screenshots/settings-rename.png)

「设置 → 重命名」：

- 开启后，后台每 20 秒检查 115 已完成离线任务
- 重命名文件夹内的视频文件本身；字幕/字体等附属文件不改名
- 单文件会保留原扩展名
- 模板变量：`${title}`、`${subgroup}`、`${season}`、`${seasonFormat}`、`${episode}`、`${episodeFormat}`、`${itemTitle}`、`${resolution}`、`${tmdbid}`
- 模板旁的 `?` 按钮会弹出全部变量及示例
- `季数` 默认 1；`集数偏移` 可用于标题集数与实际集数不一致的情况
- 解析不到集数时不会重命名，也不会移动，日志会记录错误
- 可以点击「立即处理已完成任务」手动触发一次

开启「离线后转移到保存文件夹」后：

1. 115 离线任务使用「默认离线文件夹」
2. 任务完成后按模板重命名
3. 如启用重命名，重命名成功后将文件/文件夹移动到「默认保存文件夹」
4. 只开启离线后转移、未开启重命名时，任务完成后直接移动
5. 如果只开启重命名、不开启离线后转移，则只在离线目录内改名

> 启用重命名或离线后转移后，运行结束的自动清理会暂停，避免任务在后处理前被清理。待处理数量显示在按钮右侧；失败任务会重试 5 次后标记失败。

订阅编辑弹窗里的「规则与重命名」按钮会把规则选择和预览整合在一起：

- 选择规则后直接读取当前 RSS 内容，按 BT 标题计算重命名结果
- 显示 RSS 标题、重命名结果、集数、下载状态和状态
- 同集多版本时标记「将下载 / 跳过」，跳过行会变淡
- 解析不到集数的条目显示「无法解析」，不会移动
- 按集数排序，并提示区间内缺失的集数
- 预览只计算名称，不会下载或修改文件

![规则与重命名](./screenshots/rules-preview.png)

#### 每集只下载一个版本

「设置 → 默认离线设置」默认关闭「每集只下载一个版本」，只识别并记录集数，不实际跳过；开启后：

- 按 BT 标题解析集数，同一集多个版本只提交一个
- 评分优先级：4K > 1080p > 720p，简体 > 简繁 > 繁体，内封 > 内嵌 > 外挂，HEVC > AVC，10bit > 8bit，MKV > MP4
- 解析不到集数的合集不会去重
- 预览中会显示「将下载 / 跳过」；运行结果也会显示同集跳过数量

#### 全局排除与 x.5

- `offline.global_exclude` 对所有订阅生效，每行一条，支持普通字符串和 `/正则/`。
- 订阅 filter/exclude 支持多行：filter 多行为 AND，exclude 多行为 OR。
- 支持 ani-rss 风格 `{{字幕组}}:正则`，例如 `{{今晚月色真美}}:简`。
- `offline.skip_x5` 会跳过标题中的 `12.5` 这类集数。
- 单个订阅的 `filter` / `exclude` 会在全局规则之后继续过滤。

#### 自动运行

- `auto.enabled` 打开后，服务每 `auto.interval_minutes` 分钟运行所有启用中的订阅。
- `auto.run_on_start` 让服务启动后先运行一次。
- 115 未登录、已有运行中的作业时会跳过，并写入日志。
- 自动运行提交的条目同样进入历史记录，受去重和「运行后自动清理」设置影响。

#### 通知

运行结束后，如果配置了 `notify.webhook`，会发送纯文本通知：

- **自动识别**：企业微信机器人地址使用 `msgtype=text`；其他地址按通用 Webhook 发送 `text/plain`
- **企业微信机器人**：发送 text 消息，检查返回 `errcode`
- **通用 Webhook**：body 为纯文本，不再发送 JSON
- **推送内容**：可勾选运行摘要、订阅明细、错误信息、时间

纯文本示例：

```text
AniFeed 全部订阅运行完成
状态：成功
订阅：4，匹配：20，新增：3
时间：2026-10-19T08:00:00+08:00

订阅明细：
- 药屋少女的呢喃：匹配 2，新增 2
```

设置页的「发送测试通知」使用相同发送逻辑。

> ani-rss 中与本地下载器、刮削、洗版相关的设置不完全适用于 115 离线场景；本项目已支持重命名、TMDB 关联、默认目录、离线后转移、去重、自动清理和纯文本通知。

配置写入由服务端校验并原子保存，旧文件会备份为 `config.toml.bak`。

## 登录 115

### 方式一：Cookies

1. 浏览器登录 `115.com`；
2. 打开开发者工具 → Application → Cookies；
3. 找到 `UID`、`CID`、`SEID`、`KID`，拼成 `UID=...; CID=...; SEID=...; KID=...`；
4. 粘贴到「设置 → 115 登录」并保存。

保存后 Cookies 会写入 `config.toml` 同目录的 `.cookies` 文件（权限 `0600`），`config.toml` 只保存 `cookies_file` 路径。

### 方式二：扫码登录

点击「扫码登录」，用 115 手机 App 扫描 TV 端二维码并确认。登录成功后 Cookies 会自动保存并立即生效。

## 访问令牌

Web UI 能读写 115 凭据，因此不要把未加保护的实例直接暴露到公网。两种保护方式：

1. **只监听内网 / 本机**：`server --host 127.0.0.1`，或防火墙限制来源 IP。
2. **设置访问令牌**：

```toml
[server]
host = "0.0.0.0"
port = 8115
access_token = "请换成一个足够长的随机字符串"
```

设置后：

- 页面会弹出令牌输入框，令牌保存在浏览器 `localStorage`；
- 所有 `/api/*` 和 `/add` 请求需要携带 `X-Access-Token`；
- `/api/health` 和静态页面不需要令牌，方便探活。

仍建议在公网前面加一层反向代理认证（Nginx Basic Auth、Authelia 等）和 HTTPS。

## 配置与热重载

Web UI 保存后会立即重新读取配置并重建 115 客户端：

- RSS 订阅、站点请求头、代理：立即生效；
- 115 Cookies：立即重建客户端；
- 115 限流参数：立即生效；
- 数据库路径：立即生效；
- 监听地址 / 端口 / 访问令牌：写入配置，重启后生效。

配置文件位置：

1. 当前工作目录的 `config.toml`；
2. `~/.config/anifeed/config.toml`。

如果两个位置都存在，优先使用当前工作目录。Web UI 的「设置」页右侧会显示实际使用的路径。

### 旧版配置迁移

首次打开时，程序会合并 `rss.json`、`node-site-config.json`、`.cookies` 的内容并展示。第一次在 UI 中保存后：

- 生成 `config.toml`，包含当前生效的全部内容；
- 写入 `[compat] disable_legacy = true`，之后不再回退读取旧 JSON 文件；
- 旧文件保留在磁盘上，不会删除。

这样即使把订阅删空，也不会因为 `rss.json` 还存在而「复活」旧订阅。

## 常见问题

### 打开页面提示「未登录 115」

说明还没有配置 Cookies，或 Cookies 已过期。到「设置 → 115 登录」重新粘贴或扫码。

### 运行订阅提示「已有运行中的任务」

同一时间只允许一个运行作业，避免并发触发 115 风控。等当前作业结束（概览页或任务弹窗会显示进度）再试。

### 测试订阅一直超时

说明服务器访问 RSS 站点超时。可在「设置 → 站点选项」中为对应域名启用代理，并确认代理地址可用。

### 修改端口后页面还是旧端口

端口需要重启进程。重启后使用新端口访问；如果使用 Docker，请同步修改端口映射。

### 数据库路径改了，历史记录空了

数据库路径是实际文件路径。修改后需要把旧的 `db.sqlite` 移动到新位置，或改回原路径。

### 页面样式没有更新

静态资源使用 `no-cache`，正常刷新即可。如果使用反向代理，请确认没有缓存 `/app.js`、`/styles.css`。

## API 一览

Web UI 使用同源的 JSON API，均需要 `Content-Type: application/json`（GET 除外）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |

## 开发

前端是原生的 `webui/assets/index.html`、`styles.css`、`app.js`，通过 `go:embed` 打包，无需 Node.js：

```bash
go test ./...
go run . server
```

修改静态文件后重新 `go build` 即可。若使用 `go run`，重启进程后生效。

### 设置分类

设置页分为以下二级分类：

- 账号与连接
- 离线与任务
- 重命名与 TMDB
- 通知与站点
- 实验室
- 系统信息

### 概览与移动端

- 概览页展示订阅海报墙
- 移动端底部导航：概览、订阅、任务、设置
- 封面使用 localStorage 缓存
- 订阅季数为 0 时自动识别季数

### Web UI 登录

首次访问显示初始化账号密码页面；登录后使用 7 天 HttpOnly 会话。设置中的「账号与连接」可修改账号、密码或退出登录。

### 摸鱼提醒

通知设置可开启「摸鱼提醒」，订阅超过 N 天没有新下载历史时发送提示；按订阅按天去重。

### 首页与订阅卡片

- 首页只显示今天有更新的订阅
- 订阅管理使用与首页一致的小海报卡片
- 编辑订阅不显示来源选择/ID 帮助
- 移动端底部增加日志入口

### 更新星期

订阅管理按番剧实际更新星期自然分组。星期由 TMDB 已播出集的 air_date 自动推导；没有 TMDB 数据时按最近下载日期兜底。

### 通知模板

通知设置可编辑条目通知模板，并发送「添加至云下载 / 下载完成 / 下载失败」事件；失败超时分钟数可配置。
